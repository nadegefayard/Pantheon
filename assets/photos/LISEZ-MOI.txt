automatiquement à la place (le site reste donc toujours présentable).

COMMENT LES DÉPOSER
-------------------
Le plus simple, sur GitHub : ouvrez le dossier assets/photos/ du dépôt,
bouton "Add file" > "Upload files", glissez vos photos, et renommez-les
avec les noms exacts ci-dessus avant de valider.

CONSEILS
--------
- Respectez l'orientation indiquée (VERTICAL / PAYSAGE) pour un cadrage net.
- Largeur conseillée >= 1200 px, format .jpg.
- Vous pouvez aussi me donner des liens publics vers vos photos : je les
  brancherai directement, et elles s'afficheront aussi dans le fichier
  d'aperçu.
